# Contract Evidence: executable property loop

The RMS property command family type-checks one closed observation and temporal
language, evaluates real and normalized traces through the same pure core,
searches finite probe assemblies for deterministic witnesses or counterexamples,
relates properties without implicit unbounded proof, monitors observation
prefixes without authority, and replays recorded evidence with source digests.

This evidence proves `evaluate-semantic-properties`,
`search-semantic-properties`, `analyze-semantic-properties`,
`monitor-semantic-properties`, and `replay-property-analysis`.

Focused evaluator, CLI, probe, relationship, monitor, replay, viewer, schema,
and distribution tests run under `cargo test -p rms`. Repository validation and
the maintainer release gate check contract closure and native proof integration.
